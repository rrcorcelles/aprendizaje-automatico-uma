# Práctica 3 · Calidad y preprocesado de datos

Limpieza, transformación y selección de rasgos en conjuntos de datos reales.

**Notebook:** [`preprocesado_datos.ipynb`](preprocesado_datos.ipynb)

## Temas trabajados

- Detección y tratamiento de datos incompletos
- Codificación de variables categóricas (`LabelEncoder`, one-hot)
- Estandarización de rasgos
- Selección de rasgos e importancia con Random Forest
- Comparación de clasificadores (regresión logística, k-NN, Random Forest)
- Integración y limpieza de datos del INE
- Análisis de series temporales financieras

## Datos

- `data/crx.csv`: Credit Approval (UCI)
- `data/PoblacionINE.xlsx`, `data/ViviendasINE.xlsx`: INE
- `data/DatosHistoricos_*.csv`: S&P 500, Euro Stoxx 50 y EUR/USD
