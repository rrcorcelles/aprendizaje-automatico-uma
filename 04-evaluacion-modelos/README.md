# Práctica 4 · Evaluación de modelos y métricas de rendimiento avanzadas

Metodología para evaluar, ajustar y comparar modelos de clasificación.

**Notebook:** [`evaluacion_modelos.ipynb`](evaluacion_modelos.ipynb)

## Temas trabajados

- Pipelines de preprocesado y clasificación
- Validación cruzada k-fold
- Curvas de aprendizaje y de validación
- Ajuste de hiperparámetros con `GridSearchCV`
- Curva ROC y AUC
- Métrica F1 y tratamiento de clases desbalanceadas (`RandomOverSampler`)

## Datos

- `data/ionosphere.csv`: Ionosphere (UCI)
- `data/zoo.csv`: Zoo (UCI)
- `data/breast-cancer.csv`: Breast Cancer Wisconsin (UCI)
