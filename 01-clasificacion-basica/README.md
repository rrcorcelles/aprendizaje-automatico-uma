# Práctica 1 · Algoritmos básicos de clasificación

Implementación desde cero de clasificadores lineales clásicos y visualización de conjuntos de datos.

**Notebook:** [`clasificacion_basica.ipynb`](clasificacion_basica.ipynb)

## Temas trabajados

- Visualización de muestras con Matplotlib (marcadores, colores, zoom sobre regiones)
- Perceptrón y Adaline entrenados sobre Iris
- Adaline estocástico con datos estandarizados
- Comparación del error cuadrático medio de Adaline frente a Adaline estocástico para distintas tasas de aprendizaje
- Implementación de tasas de aprendizaje decrecientes por época

## Datos

- `data/iris.csv`: Iris (UCI)
- `data/glass.csv`: Glass Identification (UCI)
